# Pup Blast: localized App Store text

Paste each block into App Store Connect: on the version page, use the language menu at the top right → **Add language**, pick the language, and fill in these fields. Screenshots are optional (the English ones are used if left empty). The game itself is still English, so each description ends with a line saying so.

Character counts were checked against Apple's limits (name 30, subtitle 30, keywords 100, promotional text 170, description 4,000). A native speaker skim before submitting is a good idea, especially for Japanese and Korean.
